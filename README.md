# Silja Line — Luxury Cruises & Polar Expeditions

An ultra-luxury maritime web application featuring immersive 3D scroll-driven storytelling, interactive ship models, curated world voyages, fleet specifications, and all-inclusive transparent standards.

---

## 🌊 Overview

**Silja Line** reimagines luxury ocean travel through intimate boutique vessels, cutting-edge naval engineering, and seamless digital storytelling.

### Key Features
- **Cinematic 3D Scroll Journey**: Multi-stage 3D and canvas-based animations with dynamic water reflections, hull lighting, and nautical telemetry.
- **Global Voyages & Expeditions (`/voyages`)**: Interactive expedition catalog with real-time filtering by region, destination, ship, and duration, detailed day-by-day itineraries, suite floorplans, and instant hold requests.
- **Our Luxury Fleet (`/fleet`)**: Architectural blueprints, technical specifications, and interactive deck-by-deck walk-throughs for:
  - *Silja Solaris* — The Grand Mediterranean & Asian Flagship
  - *Silja Aurora* — PC6 Polar Expedition & Fjord Cruiser
  - *Silja Celestis* — Caribbean & Riviera Mega-Yacht
- **The All-Inclusive Standard (`/inclusions`)**: Six pillars of freedom at sea with transparent cost comparison matrices demonstrating zero hidden fees.
- **Traveler Chronicles & Dispatches (`/stories`)**: Editorial photo essays and captain dispatches from Norway, Antarctica, Santorini, Japan, and the Caribbean.
- **Concierge & Knowledge Base (`/faq`)**: Instant keyword search and categorized FAQs covering deposits, dress codes, Starlink Wi-Fi, and 24/7 concierge requests.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & 3D Rendering**: React 19, Three.js / WebGL Canvas, Lucide Icons
- **Styling**: Vanilla CSS with custom modern glassmorphic tokens & dark-mode naval aesthetics

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/vickyy2005/Silja-line.git

# Navigate into the project folder
cd Silja-line

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
